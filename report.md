# One-Page Report: M-Shots Findings

This exercise showed that few-shot prompting can help GPT follow a pattern, but only when the task, examples, and user query are aligned. In the earlier F1 examples, the model performed well because the examples clearly established both the topic and the expected answer format. In my three custom versions, the results were weaker because the prompts mixed sentiment-classification examples with user questions that did not match the same task. As a result, GPT often stopped behaving like a classifier and instead responded like a general assistant.

In the first version, I used relationship-related examples such as "I fought with my partner" and labeled them with sentiment. However, my test input was "I want to buy a chocolate for my partner." Instead of returning a sentiment label such as Positive, GPT generated relationship advice about communication, gifts, and conflict resolution. This variation did not work well because the model was not strongly constrained to output only a label. Also, the new input was more like an action or intention than a direct opinion, so the model interpreted it as a request for advice rather than a classification problem.

In the second version, I changed the domain to AI and again provided examples labeled with sentiment. My test prompt, however, was simply "What should I do?" GPT answered with general study advice about learning neural networks instead of classifying sentiment. This result was wrong for the intended task, even though the advice itself was reasonable. The main issue was that the final user input did not resemble the training examples. The model had no explicit sentiment statement to classify, so it defaulted to a helpful conversational response.

The third version had the same weakness. I used car-related sentiment examples, but the test question was again "What should I do?" GPT returned maintenance advice instead of a sentiment label. This shows that changing the topic does not solve the core prompt-design problem. The failure came from the mismatch between the examples and the final query, not from the subject area itself.

Overall, the weaker variations did not necessarily produce factual hallucinations, but they did drift away from the intended task. In other words, the main failure was task confusion rather than made-up facts. GPT was "wrong" because it ignored the classification format and responded with open-ended advice. From this, I learned three important lessons. First, few-shot examples must closely match the shape of the final input. Second, the expected output format should be stated clearly, especially when only a short label is desired. Third, vague prompts such as "What should I do?" invite the model to improvise, which increases the chance of off-task answers. If I were to improve these prompts, I would end each version with a sentence such as "Classify the sentiment of the following sentence and answer with only one word: Positive, Negative, or Neutral." That would make the model's job much clearer and should produce more reliable results.
